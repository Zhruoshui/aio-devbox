mgr-web 重设计 · 原型总览

高保真原型，四个核心页面各自独立成文件，共用同一份 Kumo token 与新 shell。左侧图标栏可直接在页面间切换，右下角主题按钮切换深浅色（与真实应用共用 mgr.theme 键）。

重设计的重心是「布局与操作便利性」：把原来的 216px 导航栏 + 260px 沙箱树两条竖栏，合并为一条 48px 图标栏加一个可收起的侧面板，把宽度还给多窗格工作台；管理页则统一页头、筛选与卡片信息层级，让高频操作（进入工作区、启停、指派 profile）一步可达。

设计决策

Shell：一条图标栏 + 一个侧面板

  • 48px 图标栏承载页面导航与主题 / 语言切换，取代 216px 侧栏；激活项以 2px 强调色指示条标记。
  • 侧面板只在工作区出现，内容是沙箱树；点击图标栏「工作区」即可收起 / 展开，状态持久化。
  • 其他管理页收起侧面板，内容区获得全宽，容器上限仍为 1200px。
  • golden-layout 的 40px 标签条、拖拽分屏、弹出子窗口等行为不动，只延续 gl-kumo.css 的 token 皮肤。

Token：原样沿用，不另起命名

  • `mgr-web.css` 顶部的 :root / [data-mode="dark"] 块与 styles.css 一字不差，深浅色只靠 token 覆盖同步。
  • 强调色仅用于主 CTA 与激活指示；开关、复选、页面 tab 的选中态用前景色，避免蓝色泛滥。
  • 状态用「颜色 + 文字」双重表达（徽标、状态点均带文字），不依赖单一颜色。
  • 沿用 12 / 13 / 14px 紧凑刻度与 4px 节奏；标题句首大写、600 字重，不做字距与全大写。
